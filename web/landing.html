Everything in one place.

No extensions. No integrations. No API key needed for local use with Ollama — cloud providers require your own key.

Built-in RAG Engine

Upload documents and MIKA5 automatically chunks, embeds, and retrieves the most relevant fragments for every message. Per-project and per-chat knowledge bases.

Projects & Chats

Organize work into projects with isolated knowledge, system prompts and chat history. The active project and chat are marked explicitly in the sidebar. Quick Chat for ad-hoc conversations without a project.

Vision Models

Attach images to any message. MIKA5 detects vision-capable models through the provider capability probe and warns when the selected model cannot process images. Verified locally with llava and qwen2.5vl.

Cloud AI — Optional

Connect OpenAI, Anthropic, Groq, Moonshot or Alibaba Cloud Model Studio when you need them. Before the first cloud send MIKA5 asks for explicit consent and lists what will leave the device: message, history, project instructions, attachments, images and RAG context. The authorization is scoped to that provider and project, and can be revoked. API keys are stored encrypted with AES-256-GCM.

Model Tracking

Every message is tagged with the model that generated it. Model switches within a chat are highlighted inline so you always know which AI answered.

Export Anywhere

Export individual messages or full conversations to Markdown, plain text, HTML, Python, or PDF. Smart titles generated automatically from content.

First launch: getting past the Windows and macOS warnings

MIKA5 is not code-signed yet, so the system asks you to confirm the first time. It takes three steps, and only once.

Code signing policy

Windows — “Windows protected your PC”

  1. 1

    Run the installer. When the blue SmartScreen window appears, click “More info”.

  2. 2

    The window now shows the file name and “Unknown publisher”. Check that the name is the MIKA5 installer you downloaded.

  3. 3

    Click “Run anyway”. The installer continues as usual.

If Smart App Control is on, Windows blocks unsigned apps and does not offer “Run anyway”. MIKA5 cannot be installed on that PC until signed builds are available.

macOS — “Apple could not verify MIKA5”

  1. 1

    Open the .dmg, drag MIKA5 to Applications and open it once. macOS shows the warning: click “Done”.

  2. 2

    Open System Settings → Privacy & Security and scroll down to Security.

  3. 3

    Click “Open Anyway” next to MIKA5 and confirm with your password or Touch ID.

On macOS 14 or earlier you can instead right-click the app → Open → Open.

Up and running in 3 minutes.

    Install Ollama

    Download from ollama.com and install it. It runs a local server at 127.0.0.1:11434.

Frequently asked questions

Is MIKA5 free?

Yes. MIKA5 is free and open source under AGPL-3.0, with no subscriptions or hidden costs. It runs on your machine; cloud providers are optional.

Does MIKA5 require an internet connection?

No. MIKA5 works fully offline with local Ollama models. Cloud AI providers (OpenAI, Anthropic, Groq) are optional and clearly indicated.

What is the built-in RAG engine?

MIKA5 includes a Retrieval-Augmented Generation engine that automatically chunks, embeds, and retrieves relevant fragments from your documents for every message. Knowledge bases are per-project and per-chat.

What platforms does MIKA5 support?

MIKA5 is available for Windows 10+ (installer and portable), macOS (Intel and Apple Silicon DMG), and Linux (AppImage, .deb, .rpm).

Does MIKA5 collect any data or telemetry?

No. MIKA5 has no telemetry and no tracking. Conversations and documents stay on your machine in a local SQLite database, and only leave it when you choose a cloud provider and confirm the request.

How do I get past the Windows and macOS warnings on first launch?

MIKA5 is not code-signed yet, so the system asks you to confirm once. On Windows, click “More info” in the SmartScreen window, check that the file is the MIKA5 installer and click “Run anyway”. On macOS, open the app once, then go to System Settings → Privacy & Security and click “Open Anyway” next to MIKA5. If Smart App Control is on in Windows, unsigned apps cannot be installed.

How is MIKA5 different from ChatGPT?

ChatGPT is OpenAI's cloud service: your conversations are processed on OpenAI's servers and you need an account. MIKA5 is a desktop app that runs open models on your own computer through Ollama or llama.cpp, keeps conversations and documents in a local database and needs no account. Cloud providers, OpenAI included, are optional: you use your own API key and confirm what is sent before anything leaves your machine.
